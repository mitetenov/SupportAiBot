# Иллюстрации к записям FAQ

Запись в `faq.json` может назвать картинку полем `image`:

```json
{
  "question": "Где кнопка «Обновить подписку»?",
  "answer": "...",
  "keywords": ["где кнопка обновить"],
  "image": "happ-buttons.png"
}
```

Файл кладётся сюда, в `faq/images/`, и попадает в образ вместе с `faq/`
(`COPY faq/ faq/` в Dockerfile). Отдельного шага сборки не нужно.

Картинка уходит пользователю **после** текста ответа, когда эта запись встала
первой в выдаче поиска. Её же копия попадает в топик поддержки, поэтому оператор
видит ровно то, что увидел пользователь, и может ответить реплаем на неё — ответ
придёт пользователю реплаем на его копию картинки.

Ничего не ломается, если файла нет: отправка пропускается с записью в лог, текст
ответа уходит как обычно. Так что запись можно добавить до того, как нарисован
скриншот.

Telegram отдаёт `file_id` на первую загрузку, дальше картинка отправляется по
нему — файл заливается один раз за жизнь процесса.
